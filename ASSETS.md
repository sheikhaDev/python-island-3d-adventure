# Custom artwork

Raster artwork was generated with the built-in ImageGen tool and converted losslessly to WebP with transparency preserved.

- adventure-scene.webp: A sunny stylized 3D tropical landscape with a turquoise lagoon, palms, magical castle and wooden bridges. No text, panels, controls, characters or screenshots.
- luma-cutout.webp: Remove the existing Luma portrait's background while preserving her face, eyes, freckles, hair, Python clip, hoodie, backpack and welcoming pose. Genuine transparent background.
- island-props.webp: Exactly five detailed floating islands in one evenly spaced horizontal strip: candy factory, purple crystal portal, blue robot workshop, purple detective castle and golden energy city. No labels, numbers or UI.
- game-icons.webp: Twelve original toy-like 3D objects in four columns and three rows on transparency. Row 1: tropical cottage, treasure map, golden star, glowing code book. Row 2: crystal play button, padlock, crystalline tick, trophy. Row 3: light bulb, return arrow, speech balloon, progress bars. Same blue/purple/gold palette, no labels, generic emoji or UI panels.

world.js combines camera-facing illustrated island sprites with authored 3D bridges, depth, floating motion and drag rotation. It is a mixed 2D/3D scene, not a collection of fully modeled islands. Game props, portals and connecting wires are authored with CSS and SVG. Sound effects are synthesized with Web Audio; no external audio files.

Local fonts: Lalezar and Cairo from the official Google Fonts repository, distributed under the accompanying SIL OFL licenses.
