# جزيرة بايثون · مغامرة لُمى

خمس جزر تعليمية، وفي كل جزيرة لعبة واحدة مختلفة من خمس مهام:

1. مصنع البيانات: تصنيف القيم في صناديق int وfloat وstr وbool.
2. بوابات التحويل: اختيار التحويل المناسب لهدف محدد.
3. أنقذ الروبوت: ترتيب أسطر برنامج مع مدخلات وناتج محددين.
4. قلعة الأخطاء: إصلاح مقاطع كود مع شرح سبب الخطأ.
5. مدينة الطاقة: قراءة برنامج وحساب فاتورة الاستهلاك.

أسئلة البداية الخمسة تقيس المعرفة الأولية، ولا تتجاوز أي جزيرة تلقائيًا. بعد تصحيح مهام الجزيرة الخمس تظهر النتيجة، ويقود زر المتابعة مباشرة إلى الجزيرة التالية. الأخطاء تسمح بإعادة المحاولة مع تفسير. الدرجة تحتسب الإجابات الصحيحة من المحاولة الأولى. بعد مدينة الطاقة يفتح اختبار النهاية.

الأسئلة موجودة في lesson-data.js، ومنطق الألعاب في games.js، والتنقل والتقدم في app.js. تحفظ النتائج محليًا في المتصفح. مساعد لُمى تلميحات محلية جاهزة؛ لا يوجد اتصال بخدمة ذكاء اصطناعي.

النشر عبر GitHub Pages من فرع main ومجلد الجذر. الرسومات والخطوط والمكتبات محفوظة في assets، وتفاصيل التراخيص في ASSETS.md وTHIRD_PARTY_LICENSES.txt.
