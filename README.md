# جزيرة بايثون · مغامرة لُمى

أربع جزر تعليمية، وفي كل جزيرة لعبة واحدة مختلفة من خمس مهام:

1. مصنع البيانات: تصنيف القيم في صناديق int وfloat وstr وbool.
2. بوابات التحويل: اختيار التحويل المناسب لهدف محدد.
3. أنقذ الروبوت: ترتيب أسطر برنامج مع مدخلات وناتج محددين.
4. قلعة الأخطاء: إصلاح مقاطع كود مع شرح سبب الخطأ.

أسئلة البداية الخمسة تقيس المعرفة الأولية، ولا تتجاوز أي جزيرة تلقائيًا. بعد تصحيح مهام الجزيرة الخمس تظهر النتيجة، ويقود زر المتابعة مباشرة إلى الجزيرة التالية. الأخطاء تسمح بإعادة المحاولة مع تفسير. الدرجة تحتسب الإجابات الصحيحة من المحاولة الأولى. بعد قلعة الأخطاء يفتح اختبار النهاية.

الأسئلة موجودة في lesson-data.js، ومنطق الألعاب في games.js، والتنقل والتقدم في app.js. تحفظ النتائج محليًا في المتصفح. محرر Python متاح من القائمة مباشرة. لا يوجد مساعد محادثة أو اتصال بخدمة ذكاء اصطناعي.

النشر عبر GitHub Pages من فرع main ومجلد الجذر. الرسومات والخطوط والمكتبات محفوظة في assets، وتفاصيل التراخيص في ASSETS.md وTHIRD_PARTY_LICENSES.txt.

## التدريب المتكيف والمحرر

ثلاثة مستويات تتغير بعد المحاولات، و60 صيغة مدققة للأسئلة. تلميحات متدرجة: توجيه، ثم مثال مشابه، ثم تفسير. تُحفظ المهارات التي تعثرت فيها الطالبة محليًا وتظهر في التقرير مع زر مراجعة؛ تبدأ الإعادة بالموضوعات الأضعف. المحرر يستخدم Skulpt 1.2.0 المحفوظ محليًا لأوامر Python 3 الأساسية، ويشرح أخطاء التحويل والأنواع والأسماء والصياغة والمدخلات والقسمة على صفر. ليس بيئة Python كاملة ولا يسمح باستيراد مكتبات أو تشغيل حلقات ضمن هذا التدريب.

## شرح الدرس

خدمة Cloudflare Workers AI لشرح مفاهيم ضمن ملخصات مراجعة لصفحات العارض 79 و94 و101 و102 من كتاب تقنية المعلومات للصف الثامن، الفصل الأول. المرجع جزئي وليس الكتاب كاملًا، ولا توجد قاعدة استرجاع لنص الوحدة كاملًا. يُرسل السؤال عند ضغط الطالبة على زر الشرح فقط. المصادر ترفق بروابط العارض وأرقام صفحاته. تحفظ مفاتيح الخدمة خارج الموقع؛ الربط يستخدم Workers AI binding.
