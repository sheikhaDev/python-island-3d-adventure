# جزيرة بايثون · مغامرة لُمى

لعبة تعليمية للصف الثامن في عالم جزر ثلاثي الأبعاد يمكن تدويره بالسحب.

https://sheikhadev.github.io/python-island-3d-adventure/

## رحلة الطالب

1. خمسة أسئلة فقط في البداية تغطي أنواع البيانات والتحويل والإدخال وتصحيح الأخطاء وتطبيقها.
   يتغير مستوى السؤال التالي بحسب صحة الإجابة السابقة، ويبقى العدد خمسة.
2. تظهر الدرجة من 5 والجزيرة التي يبدأ منها الطالب. تُتجاوز المهارات التي أجاب عنها بصورة صحيحة في الاختبار الأولي.
3. تضم كل جزيرة لعبتي تدريب وتحديًا من خمس مهام تفاعلية: فرز وسحب، ذاكرة، توصيل، تركيب برنامج، إصلاح كود أو تحريك مقابض الطاقة. الألعاب تفتح بالترتيب.
4. يحتاج الطالب إلى 4 من 5 مهام صحيحة من أول محاولة في تحدي الجزيرة لفتح التالية. بعد الاجتياز يعود إلى الخريطة، وتضيء الجزيرة التالية وينتقل العرض إليها. عند عدم الاجتياز تنخفض الصعوبة ويعود إلى التدريب بتلميحات، ثم يعيد التحدي.
5. بعد آخر جزيرة، يفتح اختبار النهاية والتقرير.

الاختبار القصير يحدد نقطة بداية مبدئية؛ تحديات الجزر تؤكد الإتقان أثناء اللعب. خمس جزر: مصنع البيانات، بوابات التحويل، أنقذ الروبوت، قلعة الأخطاء، مدينة الطاقة.

صعوبة الألعاب في كل مهارة تبدأ من نتيجة الطالب فيها، وترتفع مع إتقان التدريب وتخف عند التعثر. القيم وترتيب البطاقات تتغير بين المحاولات.

## الرسومات والتقنية

- الخريطة تعرض رسومات الجزر التفصيلية على لوحات مواجهة للكاميرا داخل مشهد Three.js، مع جسور وعمق وحركة. الرسومات ليست نماذج يمكن مشاهدة جميع جوانبها.
- لُمى والرسومات والأيقونات أصول ثلاثية الأبعاد مرسومة خصيصًا باستخدام ImageGen. لُمى صورة شفافة ثابتة، وليست نموذجًا متحركًا.
- عند تعذر WebGL، تتاح خريطة مصورة وأزرار تحمل الوظائف نفسها.
- Three.js 0.160.0 محفوظة محليًا؛ رخصتها في THIRD_PARTY_LICENSES.txt.
- خط Lalezar للعناوين وخط Cairo للنصوص، محفوظان محليًا مع رخصتي SIL OFL داخل assets/.
- مؤثرات صوتية أصلية مركبة محليًا عبر Web Audio، تعمل بعد تفاعل الطالب مع زر لكتم الصوت. الحركة تحترم تفضيل تقليل الحركة.
- التقدم محفوظ في متصفح الجهاز. لا توجد حسابات أو مفاتيح API أو إرسال إجابات إلى خادم.
- مساعد لُمى تلميحات محلية جاهزة.
- محرر Python نشاط إضافي، لا يشترط لتجاوز الجزر. تحميل Pyodide يتطلب الإنترنت؛ تعثر في المتصفح المدمج خلال اختبارات المشروع السابق.
